# LAB 001 - PACKET CAPTURE BASICS

## Objective

Capture a small amount of traffic generated by a controlled test and identify Ethernet, IP, transport, and application-layer information.

## Scope

Use only your own computer, a private lab, and test destinations you are authorised to contact. Do not capture traffic from other users or networks without explicit permission.

## Requirements

- Wireshark
- A network interface on your own system
- A terminal
- A test domain such as example.com

## Procedure

1. Open Wireshark and select the interface currently carrying your test traffic.
2. Start a capture.
3. In a terminal, run a simple DNS lookup:

   ```bash
   nslookup example.com
   ```

4. Stop the capture after the lookup completes.
5. Apply the display filter:

   ```text
   dns
   ```

6. Select a query packet and inspect its protocol layers.
7. Select the matching response and compare the transaction ID and query name.
8. Clear the filter and inspect the surrounding traffic.

## Expected learning outcomes

After completing the lab, you should be able to identify a DNS query and response, explain the role of the resolver, and distinguish packet-level observations from assumptions about the wider network.
